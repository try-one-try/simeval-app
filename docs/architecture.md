# SimEval 架构设计

完整正文统一维护在 [架构与接口文档](架构与接口.md)。本文件保留原有链接入口，避免两份架构说明分别修改后产生差异。

## 阅读顺序

1. [整体架构与技术选择](架构与接口.md#1-整体架构与技术选择)：模块化单体、系统组成与实现范围。
2. [分层架构与业务模块](架构与接口.md#2-分层架构与业务模块)：各层职责、业务协作和实际调用链。
3. [数据设计](架构与接口.md#3-数据怎样组织)：表关系、快照、版本、约束和索引。
4. [关键业务流程](架构与接口.md#4-主要操作的执行过程)与 [AI 助手](架构与接口.md#5-ai-助手的实现)：操作怎样执行、查询哪些证据。
5. [权限、并发与性能](架构与接口.md#6-权限并发与性能)：写入保护、聊天隔离、读取方式和运行配置。
6. [代码目录](架构与接口.md#7-代码目录与文件职责)：主要源码逐个说明，同类辅助文件按目录归纳。
7. [全部接口](架构与接口.md#8-全部-http-接口)：请求、返回、权限、流事件与错误。

功能行为见各功能的 [specs](../specs/)；HTTP 契约的机器可读版本见 [OpenAPI](openapi.yaml)，可执行示例见 [接口示例](api-contract.md)。
