# 评测助手运行与手工验收

## 本机开始

1. `.env.local` 使用开发 PostgreSQL、Auth.js 和访问密码；再按 `.env.example` 设置 `OPENAI_API_KEY`、`OPENAI_MODEL`、`ASSISTANT_BUDGET_USD`。密钥不发聊天、不提交 Git。
2. 本机 Node 直连模型超时且本机有代理时，设置 `OPENAI_PROXY_URL`。这是模型专用设置，不改变 Neon 连接。API 额度与 ChatGPT 会员分开。
3. 新环境安装依赖、生成 Prisma Client，核对目标后应用迁移。此次开发库已追加助手迁移，无需 Seed 或重置。
4. `npm run dev`，退出旧会话，重新输入密码进入工作台。右下角出现 Q 版助手。
5. 在成功评测的结果／比较／异常页，点小人并选择“分析本页”。创建对话不调用模型，发送问题才调用。

## 手工体验清单

| 操作 | 应看到什么 |
|---|---|
| 问“概括当前任务最值得关注的指标” | 实际查询、逐步文字、引用与原始证据卡 |
| 比较页选好基线，问“哪些指标回退？查一下相关异常” | 按问题选择比较、列表或详情；不编造真实根因 |
| 无基线时问“提升多少” | 说明缺少基线，不捏造差值 |
| 追问、切页、收起再展开 | 保留聊天；对象变化时提示新建，不替换旧对象 |
| 刷新并打开历史 | 本次登录已保存内容仍在；不自动重跑未完成轮次 |
| 另一浏览器以同角色登录 | 看不到前一浏览器的聊天，业务任务仍共享 |
| 停止生成、快速重复发送 | 停止后不显示成功，阻止单次登录多轮并发 |
| 成功回答中保存报告 | 报告页显示当前任务指标和人工复核，私聊不公开 |
| 换评测人员查看同一报告并确认 | 可确认；工程师不能确认，服务端也检查 |
| 保存后修改样本结论／草稿，再查看／确认 | 标记过时，拒绝确认，要求重新分析 |
| 未登录直访、传别人的会话／样本 ID | 401、404 或权限拒绝 |
| 窄屏、键盘、Escape、减少动态效果 | 输入可用、焦点返回小人、降低动画 |

这些页面场景待负责人操作，不以编译成功代替验收。指派、重开仍不开放。

## 维护与错误

- 名字、欢迎语、示例问题：`src/features/assistant/content.ts`；起伏／快慢：`appearance.ts`；窗口：`assistant.module.css`。
- 分析规则：`src/server/agent/agent.ts` 的 systemPrompt；工具字段：`tools.ts`。
- 次数、上下文、超时：`config.ts`。增大前同时复核费用预留；不是越大越好。
- 401：旧登录缺访问标识或登录过期，重新登录。
- MODEL_ERROR：核对模型网络、权限或账户额度；用量不明时保留预算预留。
- SOURCE_CHANGED：重新分析来源并保存新报告。
- BUDGET_EXHAUSTED：累计账本不足下一轮预留；不删除账本来伪造用量。线上额度另行明确。
- 超时／中止不自动重试，重新发送会开始新轮次。历史只属于当前有效登录，重新登录不恢复旧私聊；报告按任务共享。

## 上线前

Vercel 设置生产模型密钥、模型名、已确定的累计预算；不要配置本机 localhost 代理。核对生产连接后只应用新增迁移，不执行 Seed／恢复。消息接口声明 `maxDuration=90`，应用内部一轮 60 秒，仍须核对平台实际限制。发布后检查登录隔离、流、真实模型、报告和移动端；本地成功不表示线上通过。
