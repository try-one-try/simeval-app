# 评测助手功能规格

2026-10-03：本地已实现真实 Agent 与聊天持久化；系统报告独立于聊天，每个成功任务只有一份当前报告。页面手工验收和生产发布待完成。聊天技术路线采用 LangChain TypeScript＋OpenAI；实施顺序见 [plan.md](plan.md)，进度见 [tasks.md](tasks.md)。

## 产品目标

用户围绕当前评测提问，助手按需查询指标、异常和人工复核，给出有来源的分析与下一步建议。用户可追问、查看历史并打开原始证据。助手只提供聊天调查；报告在报告页独立生成，使用固定模板整理当前任务数据。

第一版是单 Agent、四个只读业务工具。业务数据和评测执行仍为合成／模拟，实时模型分析与已保存示例必须分别标明。模型可解释线索，不能把相关性写成已证实的真实故障原因。

## 入口与页面

使用全站常驻的“小 AI 人”浮动按钮，点击展开聊天面板，不增加独立助手板块或侧栏导航。桌面默认右下角、可收起和放大；手机采用底部面板或近全屏对话，避开安全区、键盘和现有操作按钮。头像基于项目创作者的托腮、墨镜、浅蓝衬衫照片生成 Q 版形象；用轻量透明图片与 CSS 实现明显起伏、悬停倾斜与点击弹跳，不加载主页四向高清图集。打开面板时暂停大幅待机运动，遵循减少动态效果设置。首次展开才加载完整聊天组件，打开或切页不自动调用模型。

业务页面提供明确的页面上下文：结果页对应当前任务，比较页附已选基线，异常详情附样本。面板提供“分析本页”等快捷问题，点击只预填，发送后调用模型。任务列表／创建页无已完成任务时提供选择任务或静态帮助，不默认取最近任务。公开首页／登录页不显示助手，入口仅挂载于通过密码验证的工作台布局。助手所有接口均重新检查有效登录，不能仅依靠隐藏按钮保护数据或模型额度。

面板顶部固定展示当前对话绑定的任务和基线；主体为对话、实际工具调用状态、可展开证据卡片和追问输入框。历史入口显示当前身份创建的对话。证据默认在回答下方，展开面板后可增加侧栏。运行中可停止，失败可重新发起；无任务、任务未完成、无权限、无异常、无基线分别说明。小 AI 人提供明确的按钮名称，键盘可打开，Escape 收起后焦点返回按钮；手机面板管理焦点和滚动。

每个会话绑定一个任务和一个显式基线；同一任务与基线内切页保留对话，并更新本页可选样本提示。页面出现另一任务或另一基线时，保留原对话并显示“当前页面已切换，是否分析本页”，由用户点击开启对应的新对话，不悄悄更换历史的分析对象。没有基线允许分析当前结果，但不能生成版本提升结论。

收起面板保留会话，当前运行可在页面仍打开时继续，按钮显示运行／完成状态；显式“停止”才取消。站内跳转由共享组件保存状态；退出登录或切换身份立即取消并清空旧身份的客户端内容，服务器每轮重新授权。刷新恢复已保存历史，不恢复未完成的推理执行；浏览器关闭不承诺后台继续。

## 工具与权限

| 工具 | 提供的数据 | 边界 |
|---|---|---|
| getEvaluationSummary | 配置、状态、整体指标、异常数量 | 限当前成功且可见任务 |
| compareEvaluationMetrics | 当前任务与已选基线的分场景指标及差值 | 工程师专用，复用同口径检查和计算 |
| listAnomalySamples | 按场景、指标、复核状态分页查询异常摘要 | 限当前任务，不自动读取全部详情 |
| getAnomalyEvidence | 样本日志、已确认结论、允许查看的复核信息 | 校验样本归属，不把草稿称为最终结论 |

身份和任务范围由服务器提供，每次调用重查权限与任务可见性，不从模型参数或浏览器历史消息推断授权。评测人员不开放比较工具，也不能通过读取别人的会话获取比较结果。原页面／服务的权限缺口如存在，须在共享应用层补齐后复用。

Agent 只进行聊天与只读工具调查，不生成、更新或确认报告，也不修改评测和复核结论。建议操作通过链接进入现有页面，由用户按原权限执行。输入的日志、复核文本和工具返回的自由文本均作为数据，不能改变系统规则或提供新工具。

## 回答与证据

回答包含主要发现、支持证据、尚不能确定的事项和下一步建议。工具选择与查询次数可随问题变化，不硬编码一条调查路径。

服务器为查询结果分配证据 ID，保留任务／样本标识、查询时间及来源版本。模型引用 ID，服务器核对本轮授权取得的证据集合并生成内部链接。指标卡片的数值与差值由代码返回；无法验证的引用不显示为有效证据，失败应提示而非自动补造。

程序只能校验引用和数据边界，不能保证每句自然语言推断正确。引用相关性与事实／推测区分需要固定案例和人工检查。工具记录展示实际工具名、查询条件、摘要、耗时及成功／失败，不展示模型内部推理，不伪造进度百分比。

追问重新读取需要的当前数据；来源复核已变更时，旧回答标记为历史结果并提示重新分析。历史快照保留，不能让新证据覆盖旧回答的依据。

## 保存与运行状态

记录会话和每轮运行。服务器保存问题、带引用的文本回答、必要的问答／工具记录、证据快照、来源模式、模型、提示词版本、耗时和供应商提供的用量；用量缺失显示未知。

演示角色账号为多人共用，不能仅按 userId 隔离聊天。每次成功登录时由服务端生成随机的访问会话标识，放入受保护的认证令牌；聊天归属同时绑定该标识与账号。会话列表、详情、发送和停止均由服务端核对归属，不接受客户端自报访问会话标识。同一浏览器的有效登录期间刷新／切页可恢复自己的聊天；其他浏览器即使使用相同角色账号也不能读取。退出、登录过期或重新登录后不自动恢复旧登录的私人聊天；旧版令牌缺少标识时需重新登录。

聊天隔离不等于业务数据隔离。各访客仍共享合成评测、复核数据和当前系统报告，人工修改可被其他获准访客看到。报告按业务角色权限共享，完全不读取私人聊天。上线时设置单次登录的频率／并发限制及服务端总调用预算，防止知道密码的访问者无限消耗模型额度。

每轮状态为运行中、成功、失败、中止或超时。同一会话只允许一轮运行；重复提交通过请求标识防止重复计费调用。网络请求放在数据库事务外。请求断开尝试取消上游；进程硬终止时不能依赖 finally，后续读取按截止时间识别遗留运行。不支持自动恢复未完成的推理步骤。

第一版支持有限的近期对话；达到轮数／上下文预算时提示新建会话，不悄悄截断仍会用到的工具结果。历史可持久化不代表模型有长期记忆。

## 报告闭环

2026-10-03 修订：Agent 仅用于聊天调查，不生成或保存报告。每个成功且可见的评测任务只有一份当前系统评测报告，由报告页直接生成，固定模板读取当前指标、人工复核结论与适用限制，不调用模型、不依赖聊天轮次。工程师和评测人员均可生成或更新；最终确认仅评测人员可执行。

`POST /api/ai-reports` 只接收 `{runId}`。同一任务的数据未变化时重复生成返回原 ID 和原确认状态，不新增记录；来源变化后更新同一份报告、清空确认人及确认时间，恢复待确认状态。移除报告版本列表；历史重复记录保留在数据库但不作为当前报告展示。报告更新前的内容和确认信息写入审计，供追溯。

确认请求为 `POST /api/ai-reports/{reportId}/confirm`，接收 `{expectedSourceHash}`，与浏览器刚阅读的报告来源摘要对应。来源已变化或报告已过时则返回 `SOURCE_CHANGED`；另一位访客已更新报告、浏览器摘要与当前报告不一致则返回 `VERSION_CONFLICT`。都返回 409，不能替用户确认未核对的内容。

取消独立总览，任务状态、配置、指标与待复核数集中在评测结果页。旧总览地址重定向到对应任务结果或任务列表；Agent 的概况证据链接直接指向结果页。

报告确认复查任务、来源版本和权限，并记录审计；来源已变更则阻止确认、提示更新报告后重新核对。沿用已有报告失效机制。跨角色查看报告时过滤无权访问的数据，不能借报告绕过比较权限；共享内容只包含当前任务的概况、指标、样本人工结论与限制。来源指纹含样本编辑版本，修改草稿也可能使报告过时；更新报告不要求重新聊天或调用模型。

## 验收范围

核心路径：在比较或结果页点击 AI 人 → 发送问题 → 实际调用工具 → 查看证据 → 切页继续追问 → 刷新历史。报告路径独立：进入报告页 → 生成系统报告 → 来源变化时更新同一份 → 评测人员确认。

浮动入口额外验证：同任务切页、不同任务／基线提示、收起后再打开、放大与手机键盘、公开页未登录状态、退出／身份切换隔离，以及不遮挡主页和业务主要操作。

验收清单包含无基线、不可比、无异常、越权样本、工具错误、无效引用、来源过时、取消／超时及重复提交。阶段 8 由负责人手工功能验收，不新增或运行 Agent 自动化测试；未验证场景保持待验收，不以静态检查代替实际运行证据。历史示例不能冒充实时生成。

首版不包括文档 RAG、向量库、任意 SQL、浏览器／终端执行、多 Agent、长期记忆、无人值守长任务或独立 Agent 部署平台。
