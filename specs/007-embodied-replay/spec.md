# 具身数据同步回放（新增功能）

## 范围

工作台左侧增加“优化设计”，页面标题“具身数据同步回放”。这是独立的真实数据浏览功能，不冒充合成评测的结果，不训练或执行机器人模型。首版接入本地提供的 AgiBot World 2026 / LeRobot v2.1 单 Episode：2089 帧、30fps、约 69.63 秒。

## 行为

- 两个演示角色均可查看。复用工作台登录门禁，数据和视频接口也校验身份。媒体只允许固定 Episode 和三个摄像头，不接受任意路径。
- 头部、左手、右手视频并排；统一播放暂停、拖动时间轴、前后数据帧和 0.5/1/1.5/2 倍速。主视频提供时间，另外两路偏移超过 80ms 时校正；缓冲或定位未完成时暂停全部，恢复后再继续。普通浏览器回放不宣称科研级精确同步。
- 每次选择时间显示最近的数据帧、时间戳，以及左右末端和关节位置的状态／动作。单位未注明时显示“原始值 · 单位未注明”，不推断毫米、角度或成功与否。关节序号不推断为具体关节名称。
- 当前执行展示指令译文、记录与格式，按钮可查看原始指令，不使用设计稿里的饮料任务与示意值。原始数据只读；人工标注独立保存，注明来源。
- 工程师与评测人员共用查看和编辑权限，均可新增／修改／移除人工阶段。开始帧包含、结束帧不包含，范围 0..2089，开始必须小于结束；最多 100 段，允许重叠。点击阶段定位开始帧，当前时刻命中区间高亮。
- 标注保存在 PostgreSQL，整组版本号条件更新与审计同事务提交。冲突保留草稿，明确展示最新标注后才允许再次保存。网络失败保留草稿。首次并发创建只有一个成功。
- 加载、视频错误／重试、数据缺失、标注存储不可用、未授权与原始数据只读状态明确；任何一路不可用不得假装同步播放正常。

## 数据边界与交付

离线导入生成展示副本，保留原文件。视频转为 H.264，保留 30fps；数值按字段索引提取，不做单位转换。本地素材放被 Git 忽略的 `assets/embodied-replay/`，线上使用 Private Blob；同一受保护媒体接口支持 Range，密钥不交给客户端。数据来源与许可见 quickstart；缺素材时明确显示未配置，不伪造演示数据。

## 验收

单元检查时间查找、边界／单位映射、标注校验及媒体 Range；数据库集成验证权限、并发和审计原子性；lint、类型和构建。浏览器检查播放暂停、拖动、步进、缓冲、编辑／冲突与窄屏。人物动画不在本功能测试范围。

## 本轮体验调整（2026-10-14）

- 桌面端采用紧凑一屏布局，视频限制高度；窄屏保留必要滚动，不裁掉操作入口。14 项关节位置改为居中详情弹窗，标注编辑弹窗也居中。
- 当前执行只保留指令译文（按钮查看原文）、记录与数据格式。
- 首次无保存记录时展示四段人工时间分段预设，明确不是源数据标注或模型识别；两种身份均可修改并共同保存。已有标注不覆盖，空集合提供载入预设选项。
- 关闭该导航入口的预取，进入页面才读取时序和视频；进度按执行记录及三路视频就绪项计算，不伪装成字节下载进度。
- 数值配以反馈值、动作记录值及相较上一数据帧的变化文字。单位不明时不解释为夹爪开合、关节方向或执行成功。
- 首次加载后，播放按钮不因所选位置尚未缓冲而禁用。点击后保留播放意图，三路就绪自动播放；等待期间按钮显示“取消等待”，允许取消，拖动定位也取消此前播放意图。真实媒体错误仍停用并提供重试。
