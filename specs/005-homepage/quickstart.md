## 文件关系

### 调整鼠标手感

在 `src/features/home/avatar/controls.ts` 顶部的 `POINTER_SETTINGS` 修改参数。`horizontalTravel` 越小，同样的左右位移对应越大的动作进度；当前为 0.20。`horizontalDeadZone` 控制起步范围，当前 0.05。以人物居中的 1440px 屏幕为例，离中心 36px 内不触发左右，离中心 180px 时到达完整动作。超过尾帧不会继续扩大姿势。

先把鼠标放在视口中间高度测试：当前顶部／底部各 25% 优先走抬头／低头。要扩大左右能响应的高度范围，减小 `edgeBand`。`edgeVerticalTravel` 只控制顶部／底部的动作进度；`centerVerticalTravel` 只控制中间区域贴近人物左右中心时的上下动作进度。`advanceFrame()` 控制播放速度，与鼠标位移的灵敏度分开；换方向仍先回到待机。

使用 `npm run dev` 并打开终端打印的地址，源码保存后会热更新。`npm run start` 运行的是上次生产构建，即使刷新浏览器也不会采用新源码；需重新 `npm run build` 再重启 start。不要因为仍在看旧构建而反复调小参数。

### 调整触屏手感

手机在人物区域按下单根手指后拖动：左扶镜、右伸手、上抬头、下低头。每次按下的位置作为新起点，拖动距离决定进度；松手、取消或页面失焦后回到待机，连续换方向仍先经过共同待机帧。

`avatar/controls.ts` 的 `touchTarget()` 计算方向和进度，`TOUCH_SETTINGS` 集中维护触控手感。越过 8px 起步范围后，完整动作所需行程按人物区域宽度 × `travel` 计算，实际限制在 `minTravel`～`maxTravel` 之间；当前三个值为 `travel: 0.48`、`minTravel: 112`、`maxTravel: 192`，即行程限制为 112～192px。`travel` 越大越不敏感；这三个参数要一起调，避免上下限抵消比例变化。本轮将三个值同时加倍，同样位移对应的动作进度约减半，其他参数和播放速度不变，也不影响鼠标的 `POINTER_SETTINGS`。

`interactive-home.tsx` 只跟踪首个触点，并用 pointer capture 保持拖出人物区域后的输入；后续触点不接管这次动作。`home.module.css` 仅在 `ready` 人物区域设置 `touch-action: none`，在人物外起手仍可正常滚动页面或点击链接。静态浏览不接管触控，从静态人物区域起手也可滚动页面。

### 模块职责

`app/page.tsx → home-page.tsx → content.ts` 负责内容；`interactive-home.tsx → avatar/engine.ts → controls.ts` 负责人物、加载和输入。页面样式使用 CSS Module，避免污染登录／工作区。

`public/avatar/v1/` 仅含 57 张必需 WebP 与清单，共 11,308,846 字节图片。每方向 56 帧、每帧 1112×834；与已认可素材逐文件 SHA-256 一致，没有重新压缩。四段运动都从同一待机帧开始；换向先逐帧回程，再去最新目标，不直接切另一段视频。

首次加载 0–90% 是实收字节，90–99% 是解码验证，全部准备好才显示内容。超过 700 ms 显示进度，可主动选择静态浏览；失败可重试。图集长期缓存，但浏览器可能清理缓存。替换图片时新建 `v2/` 并同步 `AVATAR_BASE`、清单与 `next.config.ts` 缓存路径；不要覆盖已发布的不可变资源。

全部压缩图集保留在内存，解码缓存最多 6 张，约 84.9 MiB 像素数据，另有 Canvas 和临时解码开销。提前解码后续两张，缺帧时保留上一画面，不累计时间补跳。离开页面取消下载／动画、解除监听并关闭位图；隐藏标签或人物滚出视口暂停绘制。

## 浏览器检查

以下人物交互由负责人手工检查，不再编写或运行该部分自动化测试。调整动作参数后，直接按此清单体验即可。

- 全窗口左右中段、上下及四角；持续绕圈后停止，应沿共同待机帧到达最新目标。
- 各终点回到待机应自然逐帧收手，没有长停顿和跨动作拼接；动作期间不新增素材请求。
- 鼠标悬停或 Tab 聚焦两侧卡片，黑白高亮；所有链接可用，进入 `/login` 保留既有访问密码校验。
- 聚焦人物区再按方向键，Escape 回待机；其他位置方向键保持浏览器滚动。
- 手机从人物区域不同位置起手，单指向四向拖动，距离越大动作进度越大；连续换向应平滑经过待机。拖出人物区域后仍可继续当前动作，松手／取消／失焦回待机，多触点不抢占首个触点。
- 375px、平板与宽桌面无横向溢出；手机和桌面统一提示“上下左右移动鼠标探索”，触屏不提供方向按钮。在人物外滚动和点击资料／体验链接应正常；静态浏览可从人物区域滚动，也可重新加载互动。
- 减少动态效果时自动跟随关闭，手动输入直接显示姿势；无 JavaScript 时可读正文和点击登录。
- 慢网显示真实加载进度；模拟一张图下载失败后检查重试与静态入口。

通用代码检查保留 `npm run lint`、`npm run typecheck`、`npm run build`。`npm run test:unit` 继续检查其他业务功能，不包含人物交互用例。本切片不改业务 API／数据库，不需要运行 Seed、恢复数据库或数据库集成测试。
