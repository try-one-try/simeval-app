# 交互主页

## 目标与范围

公开 `/` 同时说明项目价值、开发过程并提供受控体验入口。采用黑白对话式布局：顶部 simeval. 与项目源码／开发流程／开始体验；左侧以“设计->开发->部署”为标题展示 PRD、架构接口和 Figma。“VIBE CODING, WITH A SPEC.”与 Spec Kit 合成一处：先说明本项目如何用它写规格、计划和任务，再依次链接本项目 `specs/` 文档与 GitHub 官方开发工具；之后展示开发步骤。中央为四向人物；右侧用简短正文介绍产品定位、实际可用流程与登录按钮；底部保留技术栈及合成演示声明。公开开发流程文档包含从代码、数据库、环境变量、域名到上线验收的部署过程。Figma 只作布局灵感，以本轮内容和已认可的高清 Demo 为交互基线。

## 行为与验收

- 无会话也能访问主页；开始体验进入现有 `/login`，工作区权限和访问密码规则保持有效。
- PRD、架构接口及开发流程直接链接本仓库 GitHub `main/docs/`；原型链接现行 Figma 工程页。
- 文案与链接集中维护，不需要修改 Canvas 引擎。关键模块有中文职责、资源回收及动画连续性的注释。
- 全窗口鼠标驱动：左扶镜、右伸手、上抬头、下低头；上下边带包括四角，4% 滞回避免边界抖动。跨方向沿原动作回待机，再进入最新方向；每次最多推进一帧，预解码避免回程停顿。
- 手机在互动准备完成的人物区域内单指拖动：以手指按下位置为起点，上下左右对应同样四个动作，拖动距离决定动作进度；采用较长拖动行程，避免小幅移动就做到完整动作，播放速度保持现有设定。只跟踪首个触点，拖出人物区域后仍延续当前拖动。连续换方向沿共同待机帧平滑转换；松手、取消或页面失焦时回待机。仅该区域接管触控手势，人物外仍可正常滚动页面和点击链接；静态浏览的人物区域也可正常起手滚动。
- 保持每方向 56 帧、1112×834 的现有高清素材；不下载 MP4，不重新生成人物。全量压缩素材加载并验证后显示；超过 700 ms 显示字节进度。失败可重试或明确选择静态浏览，不能困在加载页。
- 解码缓存最多 6 张图集；动作期间不再下载。隐藏标签页停止动画，卸载取消网络、事件和动画并释放位图。
- 人物区域正常显示时，手机和桌面统一只显示“上下左右移动鼠标探索”；不显示顶部英文标签、方向按钮或待机按钮。桌面鼠标仍可在全窗口驱动人物；键盘聚焦人物区可用方向键与 Escape，减少动态效果时手动操作直接显示姿势。触屏页面保持可读，人物外正常滚动，不提供独立的方向按钮。静态浏览后保留重新加载互动入口。
- 两侧框默认灰白，悬停或键盘聚焦高亮；内容和动作不遮挡链接。375px 无横向溢出，放大文字不裁剪正文；无 JavaScript 时仍能阅读及进入登录。
- 报告生成尚未实现，不在主页宣称已经可用；合成数据／模拟执行显著标注。

## 验证

原主页验证范围包含 lint、类型、动作映射及调度单元测试、生产构建，以及浏览器桌面／手机、四向与四角、绕圈、逐帧回程、加载失败重试、减少动态效果、键盘、静态降级与登录跳转；历史结果见 [维护与验收](quickstart.md#本轮证据)。2026-10-04 手机拖动改动按负责人约定不运行测试或构建，人物区拖动、释放／取消／失焦、多触点、人物外滚动和链接、既有输入方式待负责人手工体验。公网冷加载速度待实际部署测量。
