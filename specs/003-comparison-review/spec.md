# 模型对比与异常复核
**阶段 5，2026-09-27 开始。** 阶段 4 已由负责人确认继续；沿用认可的黑白原型与已调整的侧栏。原阶段 6 报告工作顺延至阶段 8，届时重新讨论 Agent 与报告设计，本规格不授权实现报告生成／确认。

## 1. 主线
同一任务的正文采用双向流程导航：工程师为评测结果 ↔ 模型对比 ↔ 异常复核 ↔ 报告；评测人员为评测结果 ↔ 异常复核 ↔ 报告。标题上方左侧提供明显的白底次级返回按钮，正文后提供主操作继续；角色不允许的板块不出现。任务、显式选择或取消的基线、异常筛选随链接保留，不重新选任务；样本详情返回原异常列表。报告尚未开放，只完善现有占位页的返回导航，不提前实现报告业务。
工程师选任务 → 查看本次指标／选择同口径基线 → 从指标下钻异常 → 读日志并编辑草稿 → 切评测人员确认／修改 → 看最新结论与历史。侧栏先选任务，正文链接保留 runId；无基线可直接复核。

## 2. 对比规则
- 没有可选兼容基线时，明确显示“暂无同口径历史基线”，不提示用户选择不存在的历史记录。
- 仅工程师使用模型对比。两个任务成功、同项目／数据版本／Benchmark／Episode／Seed，模型版本不同。
- 历史基线可在对比页选择，只改变当前查看，不改任务原始配置；不选时仅显示当前指标。原任务已引用但被隐藏的基线可继续读取，不能任意引用隐藏任务。
- 以指标 key＋scenarioKey 配对，说明单位、方向、两侧样本数；单位／方向／样本数不一致或缺指标时标为不可比，不生成差值或改善结论。
- 差值为候选减基线；百分比指标写百分点（pp），不写相对百分比。总体与遮挡场景分别展示；回退不等于已经判断模型原因。
- 首屏短结论与两个关键指标，完整指标按需展开；明显的异常按钮，指标下钻携带场景和指标筛选。
- 完成页保留结果供核对；工程师的主按钮进入当前任务的模型对比，评测人员进入异常复核。基线选择用明确的浅底边框；增量补充 v2.1／v2.2 历史合成结果，与 v2.3 同口径，可选项不足时不混入不兼容任务。

## 3. 异常与结论
- 两身份共享读取成功且未删除任务的异常。列表有场景／指标／待复核筛选、分页、进度；空、错、不存在分别处理。详情显示任务、样本、日志来源和明确编辑入口，不冒充真实媒体。
- 编辑弹层提供“填入演示结论”，依据当前合成日志填入可修改的示例，明确替换当前输入；不自动保存或确认，不把日志现象写成已证实原因。
- 草稿与最终结论分别保存。工程师只能编辑本人任务的草稿；评测人员可编辑共享草稿、确认／修改最终结论。自由文本 trim 后 1–4000 字，没有分类步骤。
- 未确认样本和有新草稿的样本以红字注明评测人员责任。草稿不覆盖已有确认；确认后清除草稿，保留原结论和修改历史。
- expectedVersion 从 1 开始，所有写入核对当前版本；冲突不覆盖他人、不清空输入。可读取最新内容后再次核对保存。
- 最终内容改变才增加 confirmedRevision；保存相同最终内容不提高确认修订号。编辑版本、历史、审计和已有报告的过时标记在同一事务完成。草稿不会使引用当前最终结论的报告过时。
- 软删除的任务不能继续查看或编辑；写入锁任务行，避免与删除竞争。历史记录保留；旧确认迁移为修订 1，来源不完整时明确显示历史记录。
- 当前没有指派、重开或批量复核；通过修改最终结论处理判断修订，指派／重开保留后续设计状态。
