本轮 Schema 有追加字段，目录新增模型／数据／基准。先在原开发终端按 Ctrl+C，再在仓库根目录依次运行：

~~~powershell
npm run db:generate
npm run db:deploy
npm run db:catalog
npm run dev
~~~

generate 更新数据库访问代码；deploy 追加迁移；catalog 增量补目录与十条核心示例，保留已有结果、人工结论和删除状态；dev 启动网页。新环境的完整 Seed 已含目录和示例，不必再单独 catalog。以后平时只需 dev，不重复初始化。

访问 http://localhost:3000/login。若还在运行旧 Prisma Client，刷新网页无法解决；必须重启原服务。

## 3. 阶段 4 实现后再验

建议按下面顺序，约 5 分钟。每项记录通过／不通过；有问题提供地址和现象。

| 步骤 | 操作 | 应看到什么 |
|---|---|---|
| 1 自主配置 | 工程师进入创建；手填名称并展开下拉，或点击“使用演示配置” | 默认不选模型／数据／Benchmark；有 v2.4／v2.5、三数据集、两基准；快捷填入不会直接创建，可继续修改 |
| 2 质量两步 | 演示配置 → 检查数据质量 | 保留任务名；WARNING 未勾选不能提交。返回改 clean v1 得 PASSED、无需接受；invalid v1 为 FAILED，禁止创建。clean＋遮挡基准不兼容，配置页说明原因 |
| 3 无基线执行 | 使用演示配置，保留“不对比历史结果”，接受质量警告后创建 | 新 ID 与名称显示；服务器满 1 秒可运行、满 4 秒可完成，页面每 1.5 秒同步，正常约 4–5 秒看到完成，保存四指标、两预置证据；81%／13%，目标 80% 达到，但不等于可发布 |
| 4 任务上下文 | 点“进入模型对比”，刷新；再点侧栏总览／任务／比较／异常／报告 | 正文直接到同一任务；刷新不换任务。侧栏先单选，没有默认偷选最近任务；切另一任务显示其名称／ID，预置示例有标识 |
| 5 管理 | 另建任务，立即取消；更多设置勾故障演示，创建后失败再重试 | 取消需确认、保留记录且无结果。重试新 ID，原 FAILED 保留；Escape 关闭弹层，焦点恢复 |
| 6 删除 | 在任务选择页单选本人已结束的测试任务，点击删除；先按 Escape，再打开确认 | 弹层说明隐藏与引用保留。确认后列表不再显示；刷新仍隐藏。运行中不能删、固定示例受保护；不要删除需要保留的演示记录 |
| 7 两身份 | 切评测人员，再选刚完成任务 | 共享任务和红色“待复核／需评测人员复核”可见；没有创建／取消／重试／删除。复核编辑和 AI 报告尚未开放 |
| 8 窄屏与键盘 | 375px 左右宽度，Tab 操作表单／单选／菜单 | 没有横向溢出；关键按钮可达，菜单和弹层 Escape 可关闭；展开侧栏不推挤正文 |

每位工程师最多三个 QUEUED／RUNNING 任务；满额给出明确错误，不清空输入。取消／终态释放名额。容量竞争、重复提交、软删除引用和越权由数据库测试验证，负责人不必手工构造 HTTP。

模型对比、结论编辑和报告业务在阶段 5–6；本阶段仅交付它们的任务入口与上下文，不把占位提示算作完整闭环。模拟没有后台 Worker，离开任务页后，下次打开／同步才推进保存状态。

### 任务防重名：后续手工核对（2026-10-05）

以下为后续核对步骤，本轮按负责人约定未执行。防重名修订不需要新增迁移，也不自动修改历史名称。

| 操作 | 应看到什么 |
|---|---|
| 使用固定示例名，或给同项目已有名称加首尾空格、改变大小写后创建 | 409 `RUN_NAME_CONFLICT`，`fieldErrors.name` 提示；全部输入保留，返回配置步骤编辑名称。其他创建者的未删除任务也占用名称 |
| 软删除本人已结束的普通测试任务后，用原名称创建 | 可创建新 ID，旧任务及引用保留；固定示例仍受删除保护 |
| 同一个创建／重试幂等键和内容重复提交 | 200 返回原 ID 和原名称；不误报重名、不新增任务或编号 |
| 对 FAILED 任务重试，已有“原名 · 重试 1”时再次重试 | 从 1 起跳过占用编号，生成“原名 · 重试 2”等新名称；原名较长时截短，含后缀总长不超过 120 字 |
| 同项目不同账号并发创建同名任务 | 最多创建一条；另一请求返回重名错误。项目行锁保护名称分配，账号行锁继续保护容量 |
