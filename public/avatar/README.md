# 主页人物运行素材

`v1/` 是已认可的四向动作 WebP 包，57 张图片与一份运行清单。人物由项目创建者提供并用于本项目主页；源视频和私人参考照片不在公开仓库内。

每方向 56 帧，单帧 1112×834，每张动作图集为 2×2 帧；四向共用待机姿势。文件直接复制已认可的高清版本，未再次压缩。运行图片共 11,308,846 字节，浏览器完整加载并检查解码后展示。

此目录使用不可变长期缓存。更新必须创建新的版本目录，并同步 `src/features/home/avatar/engine.ts` 的 `AVATAR_BASE` 与 `next.config.ts`。素材内部说明与逐文件大小以 `v1/motion.json` 为准。交互与内容维护见 `specs/005-homepage/quickstart.md`。
